# FIRMWATCH ロゴの使い方

![](kit/lockup-horizontal.svg)

## 考え方
機材の表示器（7セグメント）で「F.」と出した形。赤い小数点は、バージョン番号（10.1.2 の「.」）と、確認が要ることを知らせるタリーの赤を表す。

## ファイル（`kit/`）
| ファイル | 使う場面 |
|---|---|
| `symbol.svg` | 記号だけ（白・明るい地） |
| `symbol-reversed.svg` | 記号だけ（黒い地） |
| `symbol-black.svg` / `symbol-white.svg` | 1色で刷るとき |
| `lockup-horizontal*.svg` | 横組み（通常・黒1色・白1色・黒地） |
| `lockup-stacked.svg` | 縦組み |
| `app-icon.svg` / `app-icon-maskable.svg` | アプリのアイコン（角丸は付けない。端末が丸める） |
| `favicon.svg` / `badge.svg` | ブラウザのタブ、Android の通知 |

## 色
| 名前 | HEX | 使いどころ |
|---|---|---|
| 墨 | `#111111` | F と文字 |
| タリーの赤 | `#E0001B` | 小数点だけ |
| 表示器の白 | `#F2F3F4` | 黒い地の上の F と文字 |

赤は小数点だけに使う。F や文字を赤くしない。

## 決まり
- まわりの余白：小数点の幅（記号の高さの約1/6）以上をあける
- 最小の大きさ：記号は 16px、横組みは高さ 20px まで
- 傾き・色・字間を変えない。影やグラデーションを付けない
